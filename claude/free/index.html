클로드 무료로 어디까지 되나

클로드 무료는 기능이 잘려 있는 방식이 아니라 사용량으로 조절되는 방식입니다. 그래서 짧게 쓰면 유료와 체감 차이가 거의 없고, 길게 붙잡으면 갑자기 막힙니다. 그 경계가 어디인지 정리했습니다.

무료로 되는 것

클로드 무료 계정으로 웹·iOS·안드로이드·데스크톱 어디서나 쓸 수 있습니다. 웹 검색과 메모리가 들어 있고, 코드 생성도 됩니다. 기능 목록만 보면 유료와 크게 다르지 않습니다.

이게 다른 서비스와의 차이입니다. 챗GPT 무료는 GPTs 제작이 막혀 있고, 제미나이 무료는 동영상 생성과 Deep Research 가 없습니다. 클로드는 기능을 잠그는 대신 사용량으로 조절합니다.

그래서 어디서 막히나

무료의 벽은 대화가 길어질 때 옵니다. 짧은 질문 몇 개는 문제없지만, 긴 문서를 통째로 넣거나 코드베이스를 분석시키면 한도에 금방 닿습니다.

  • 번역·요약·문장 다듬기 — 무료로 충분합니다. 한 번에 끝나는 작업이라 한도를 거의 안 씁니다
  • 긴 글 쓰기 — 구조 잡고 문단 늘리고 다듬는 과정에서 대화가 길어집니다. 한 편 쓰다가 막힐 수 있습니다
  • PDF·문서 분석 — 파일 하나가 대화 하나만큼의 한도를 씁니다. 여러 개 비교하려면 무료로는 어렵습니다
  • 코드베이스 분석 — 무료로는 사실상 불가능합니다. 파일 몇 개 넣으면 끝납니다

기준을 하나로 정리하면 이렇습니다. 하루 한 시간 이내로 가볍게 쓰면 무료로 충분하고, 업무에 붙여 쓰기 시작하면 그날 바로 부족해집니다.

Pro 로 올라갈 시점

신호는 하나면 충분합니다. 작업 도중 한도에 걸려 손이 멈추는 일이 반복되는가. 이게 일주일에 두세 번 이상이면 그때입니다.

Pro 는 월 $20 이고, 연간 결제하면 월 $17(연 $200)입니다. 세 서비스 중 개인 플랜에 상시 연간 할인이 있는 건 클로드뿐이라, 1년 이상 쓸 게 확실하면 연간이 낫습니다.

Pro 로 올라가면 Opus·Sonnet·Haiku 를 쓸 수 있고 Fable 도 제한적으로 접근됩니다. Claude Code, Cowork, Design, Science 가 포함되고 프로젝트가 무제한이 됩니다. Claude Code 를 매일 쓴다면 Pro 한도도 금방 닿아서 그다음은 Max 를 봐야 합니다.

없습니다. 계정을 여러 개 만드는 것은 이용약관 위반이고, 계정 공유 서비스는 정지되면 남은 기간이 그대로 사라집니다. 무료 한도가 부족하면 Pro 로 올라가거나, 무료 한도가 더 넉넉한 서비스를 같이 쓰는 것뿐입니다.

실제로 많이 쓰는 방법은 둘을 병행하는 것입니다. 가벼운 질문은 제미나이 무료로, 긴 글과 코드는 클로드 무료로 나눠 쓰면 각각의 한도를 따로 쓰게 되어 체감 여유가 꽤 늘어납니다. 둘 다 무료라 비용도 없습니다.

자주 묻는 질문

2026년 9월 7일 공식 요금제 페이지 확인 기준입니다.

클로드 무료로 어디까지 쓸 수 있나요?

웹과 iOS, 안드로이드, 데스크톱 어디서나 쓸 수 있고 웹 검색과 메모리, 코드 생성까지 됩니다. 기능 목록만 보면 유료와 크게 다르지 않고 사용량으로 조절되는 구조입니다. 하루 한 시간 이내로 가볍게 쓰면 무료로 충분합니다.

클로드 무료로 이미지를 만들 수 있나요?

없습니다. 클로드는 유료 플랜에서도 이미지 생성을 제공하지 않습니다. 이미지가 필요하면 제미나이 무료가 이미지 생성을 포함하고 있어 그쪽이 낫습니다.

클로드에는 왜 중간 요금제가 없나요?

무료 다음이 바로 Pro 20달러입니다. 챗GPT 는 Go 8달러, 제미나이는 AI Plus 7,500원이라는 중간 단계가 있지만 클로드에는 없습니다. 조금만 더 쓰고 싶은 정도라면 다른 서비스의 저가 플랜을 쓰는 편이 나을 수 있습니다.

무료에서 Pro 로 언제 올라가야 하나요?

작업 도중 사용량 한도에 걸려 손이 멈추는 일이 일주일에 두세 번 이상 반복될 때입니다. Pro 는 월 20달러이고 연간 결제하면 월 17달러가 됩니다. 세 서비스 중 개인 플랜에 상시 연간 할인이 있는 것은 클로드뿐입니다.
