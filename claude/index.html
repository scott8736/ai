무료로 어디까지 되나

클로드 무료는 웹·모바일·데스크톱 어디서나 쓸 수 있고 웹 검색과 메모리, 코드 생성까지 됩니다. 기능이 잘려 있다기보다 사용량으로 조절되는 구조라, 짧게 쓰면 유료와 체감 차이가 크지 않습니다.

무료의 벽은 대화가 길어질 때 옵니다. 긴 문서를 통째로 넣거나 코드베이스를 분석시키면 한도에 금방 닿습니다. 하루 한 시간 이내로 가볍게 쓰면 무료로 충분하고, 업무에 붙여 쓰기 시작하면 그날 바로 부족해집니다.

무료로 버틴다면 굳이 결제할 이유가 없습니다

어느 작업에서 한도가 먼저 차는지, 하루에 몇 번씩 끝나는지, 한도를 늘리는 방법이 있는지까지 따로 정리했습니다.

Pro 와 Max, 언제 올라가나

Pro 는 월 $20 입니다. Opus·Sonnet·Haiku 를 쓸 수 있고 Fable 도 제한적으로 접근됩니다. Claude Code, Cowork, Design, Science 가 포함되고 프로젝트는 무제한입니다. 개인이 쓰기에는 대부분 여기서 끝납니다.

Max 로 올라가야 할 신호는 명확합니다. Claude Code 를 매일 쓰는데 작업 도중 사용량 한도에 걸려 손이 멈추는 일이 반복된다면, 그때가 Max 를 볼 시점입니다. Max 는 Pro 대비 5배($100) 또는 20배($200) 사용량을 줍니다. 기능이 늘어나는 게 아니라 한도만 늘어나므로, 한도에 안 걸리는 사람에게는 돈만 더 내는 셈입니다. 클로드 코드를 쓰려고 올라가는 경우라면 어느 구독까지 필요한지 따로 정리해 뒀습니다 — 무료 플랜에는 아예 들어 있지 않습니다.

연간 결제 — 세 서비스 중 유일합니다

이건 짚고 갈 만합니다. 챗GPT 는 개인 플랜에 연간 할인이 아예 없고, 제미나이는 프로모션이 수시로 바뀝니다. 클로드만 개인 Pro 에 상시 연간 할인이 있습니다.

월 $20 을 연간으로 묶으면 월 $17(연 $200)이 됩니다. 1년에 $40, 약 5만 원 차이입니다. 1년 이상 쓸 게 확실하면 연간이 낫고, 아직 확신이 없으면 월 결제로 두세 달 써본 뒤 바꿔도 늦지 않습니다.

Team 은 언제부터 의미가 있나

Team 은 표준석 인당 $25(연간 결제 시 $20)입니다. 더 높은 사용량이 필요한 사람을 위한 프리미엄석은 인당 $125 로 따로 있습니다. Pro 두 개를 사는 것보다 비싸므로, 단가만 보고 갈 이유는 없습니다.

Team 의 값어치는 SSO, 중앙 청구, 엔터프라이즈 검색, 커넥터 관리 같은 관리 기능에 있습니다. 회사 카드로 한 번에 결제하고 인원을 붙였다 뗐다 해야 하는 상황이라면 그때 넘어가는 게 맞습니다.

해지와 환불

claude.ai → Settings → Billing → Cancel 순서입니다. 월 중간에 해지해도 결제한 기간이 끝날 때까지는 Pro 기능을 그대로 쓸 수 있습니다. 연간 결제를 중도 해지하는 경우 잔여 기간 처리 방식이 다를 수 있으니 결제 화면에서 확인하세요.

자주 묻는 질문

2026년 9월 7일 공식 요금제 페이지 확인 기준입니다.

클로드 무료로 어디까지 쓸 수 있나요?

웹과 모바일, 데스크톱 어디서나 쓸 수 있고 웹 검색과 메모리, 코드 생성까지 됩니다. 기능이 잘려 있다기보다 사용량으로 조절되는 구조라 하루 한 시간 이내로 가볍게 쓰면 무료로 충분합니다. 긴 문서나 코드베이스를 분석시키면 한도에 금방 닿습니다.

클로드 Pro 와 Max 중 무엇을 골라야 하나요?

Max 는 기능이 늘어나는 게 아니라 사용량 한도만 Pro 대비 5배 또는 20배로 늘어납니다. Claude Code 를 매일 쓰는데 작업 도중 한도에 걸려 손이 멈추는 일이 반복될 때가 Max 로 올라갈 시점이고, 그렇지 않으면 Pro 로 충분합니다.

클로드 연간 결제 할인이 있나요?

있습니다. 월 20달러인 Pro 를 연간으로 결제하면 월 17달러, 연 200달러가 됩니다. 세 서비스 중 개인 플랜에 상시 연간 할인이 있는 건 클로드뿐입니다. 챗GPT 는 개인 플랜에 연간 할인이 없습니다.

클로드 구독은 어떻게 해지하나요?

claude.ai 에서 Settings → Billing → Cancel 순서입니다. 월 중간에 해지해도 결제한 기간이 끝날 때까지 Pro 기능을 쓸 수 있습니다. 연간 결제를 중도 해지하는 경우 잔여 기간 처리 방식이 다를 수 있으니 결제 화면에서 확인하세요.
