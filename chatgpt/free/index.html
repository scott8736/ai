챗GPT 무료로 어디까지 되나

챗지피티 무료로 쓸 수 있는 범위와 막히는 지점을 실제 한도 숫자로 정리했습니다. 결론부터 말하면 쓸 수는 있지만 진지하게 쓰기는 어렵습니다. 다만 무료로 충분한 경우도 분명히 있어서, 그 경계를 어디에 둘지가 이 글의 내용입니다.

✓ 실제 메시지 한도 ✓ 무료로 충분한 경우 ✓ 유료로 갈 시점 ✓ Go 라는 중간 선택지

한 줄 요약

무료 챗GPT 는 5시간당 10메시지입니다. 기본 모델만 쓸 수 있고, GPTs 는 남이 만든 걸 쓸 수는 있지만 직접 만들 수는 없습니다. 한 번에 끝나는 작업이면 무료로 충분하고, 대화를 주고받아야 하는 작업이면 부족합니다.

5시간당 10메시지가 실제로 어느 정도인가

숫자만 보면 감이 안 옵니다. 실제로 쓸 때 이렇습니다.

  • 번역이나 맞춤법 검사 — 한 번 붙여넣고 답을 받으면 끝입니다. 10개면 하루치로 넉넉합니다
  • 이메일 초안 쓰기 — 초안 하나 받고 "좀 더 짧게" 두어 번 고치면 3~4개를 씁니다. 하루에 두세 통이면 아슬아슬합니다
  • 코드 디버깅 — 오류를 붙여넣고 답을 받고 다시 물어보는 과정이 반복됩니다. 한 문제 푸는 데 10개를 다 씁니다
  • 긴 글 쓰기 — 구조 잡고 문단 늘리고 다듬는 과정에서 20~30개는 기본입니다. 무료로는 불가능합니다

그리고 한도에 걸리면 5시간을 기다려야 합니다. 작업 중간에 막히면 그날 일이 멈추는 것과 같습니다. 이게 무료의 진짜 비용입니다.

무료로 충분한 사람

의외로 많습니다. 아래에 해당하면 유료로 올라갈 이유가 없습니다.

  • 번역·요약·맞춤법처럼 한 번에 끝나는 작업이 대부분인 경우
  • 하루에 몇 번, 생각날 때 검색하듯 쓰는 경우
  • 이미 제미나이나 클로드 중 하나를 유료로 쓰고 있어서 챗GPT 는 비교용으로만 여는 경우
  • 대학생이라 제미나이 12개월 무료를 쓰고 있는 경우 — 이쪽이 훨씬 이득입니다
대학생이면 다른 답이 있습니다

챗GPT 는 한국 학생 할인이 없지만, 제미나이는 대학생에게 AI Pro 를 12개월 무료로 줍니다. 월 29,000원짜리를 1년간 안 내는 것이니 약 35만 원어치입니다.

유료로 넘어갈 시점

판단 기준은 하나면 충분합니다. "5시간 안에 열 번 이상 물어보게 되는가." 이게 일주일에 두세 번 이상 벌어진다면 그때가 유료를 볼 때입니다.

다만 여기서 바로 Plus($20)로 가지 마세요. 2026년에 Go 가 월 $8 로 생겼습니다. 메시지 한도가 무료의 약 10배로 늘어서, "무료로는 답답한데 $20 은 부담"인 구간을 정확히 메웁니다. 모델은 기본 모델 그대로고 GPTs 제작은 여전히 안 되지만, 한도 때문에 막히는 게 문제였다면 Go 로 해결됩니다.

Plus 가 필요한 건 모델 성능이 필요할 때입니다. GPT-5.3·5.5 의 추론, Deep Research, 고급 음성 모드, GPTs 제작. 이 중 하나라도 이름이 눈에 들어온다면 Plus 로 가는 게 맞고, 아니라면 Go 로 한 달 써보고 결정해도 늦지 않습니다. 결제를 정하셨다면 유료 결제 전에 확인할 것을 먼저 보시기를 권합니다. 해지 경로를 모르면 이중 결제가 납니다.

무료 한도를 늘리는 방법은 없나

없습니다. 검색하면 여러 방법이 나오는데 정리하면 이렇습니다.

  • 계정 여러 개 만들기 — 이용약관 위반입니다. 계정이 정지되면 대화 기록까지 전부 사라집니다
  • VPN 으로 다른 국가 접속 — 한도는 국가별로 다르지 않습니다. 효과가 없습니다
  • 계정 공유 서비스 — 약관 위반이고, 정지되면 남은 기간이 그대로 날아갑니다. 이 사이트가 그런 링크를 넣지 않는 이유도 그것입니다
  • 공식 쿠폰·프로모션 코드 — 상시로 운영되지 않습니다. 할인 총정리에 정리해 뒀습니다

무료 한도가 부족하다면 답은 Go 로 올라가거나, 무료 한도가 더 넉넉한 다른 서비스를 같이 쓰는 것뿐입니다.

자주 묻는 질문

2026년 9월 7일 공식 요금제 페이지 확인 기준입니다.

챗GPT 무료는 하루에 몇 번 쓸 수 있나요?

5시간당 10메시지입니다. 하루 기준으로 고정된 숫자가 아니라 5시간 단위로 리셋되는 방식이라, 한도에 걸리면 5시간을 기다려야 합니다. 번역이나 요약처럼 한 번에 끝나는 작업이면 넉넉하지만 코드 디버깅처럼 주고받아야 하는 작업은 한 문제에 10개를 다 씁니다.

챗GPT 무료로 GPTs 를 만들 수 있나요?

만들 수 없습니다. 남이 만든 GPTs 를 사용하는 것은 무료에서도 되지만 직접 제작하려면 Plus 가 필요합니다. 월 8달러인 Go 에서도 제작은 안 됩니다.

무료 메시지 한도를 늘리는 방법이 있나요?

없습니다. 계정을 여러 개 만드는 것은 이용약관 위반이고 정지되면 대화 기록까지 사라집니다. VPN 으로 국가를 바꿔도 한도는 같습니다. 한도가 부족하면 Go 로 올라가거나 무료 한도가 더 넉넉한 제미나이를 같이 쓰는 방법뿐입니다.

무료에서 유료로 언제 올라가야 하나요?

5시간 안에 열 번 이상 물어보게 되는 일이 일주일에 두세 번 이상 벌어질 때입니다. 다만 바로 Plus 20달러로 가지 말고 Go 8달러를 먼저 보세요. 한도 때문에 막히는 게 문제였다면 Go 로 해결되고, 모델 성능이나 Deep Research 가 필요할 때만 Plus 가 의미 있습니다.
