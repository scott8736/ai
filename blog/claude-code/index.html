클로드 코드 요금 — 따로 결제하는 게 아닙니다

"클로드코드 요금제"를 찾아도 안 나오는 이유가 있습니다. 별도 요금제가 없기 때문입니다. Pro 와 Max 구독에 들어 있고, 무료 플랜에는 없습니다. 그래서 실제로 정할 것은 요금제가 아니라 어느 구독까지 올라갈 것인가입니다.

한 줄 요약

클로드 코드는 구독에 딸려 오는 도구지 따로 파는 상품이 아닙니다. Pro(연간 월 $17 · 월간 월 $20)부터 포함되고 Max(월 $100부터)에서 한도가 커집니다. 무료 플랜에는 들어 있지 않습니다. 그래서 "얼마인가"의 답은 곧 "Pro 냐 Max 냐"이고, 그건 한도에 얼마나 자주 걸리느냐로 정해집니다.

표에서 먼저 볼 줄은 Free 입니다. 무료 클로드로는 클로드 코드를 쓸 수 없습니다. "클로드코드 무료"로 검색해서 방법을 찾고 계셨다면 여기서 끝납니다 — 무료로 되는 범위는 웹·앱에서 대화하는 데까지입니다.

① Pro 로 충분한 사람

Pro 는 5시간 세션당 무료의 최소 5배 사용량입니다. 기준을 시간으로 바꿔 말하면, 하루에 한두 시간 코드를 맡기고 나머지 시간에는 직접 손보는 방식이면 Pro 에서 한도에 부딪히는 일이 드뭅니다.

연간 결제를 먼저 보세요. 클로드는 세 서비스 중 개인 플랜에 상시 연간 할인이 있는 유일한 쪽입니다. 월 $20 이 $17 이 되니 1년에 $36, 대략 5만 원 차이입니다. 챗GPT 는 개인 플랜에 연간 할인이 아예 없고 제미나이는 프로모션이 수시로 바뀝니다. 한 달 쓰고 그만둘 게 아니라면 연간이 거의 항상 유리합니다.

② Max 가 필요해지는 지점

Max 는 월 $100 부터이고, Pro 대비 5배와 20배 중에서 고르는 구조입니다. $100 은 원화로 13만 원대라 개인이 가볍게 지를 값은 아닙니다. 그래서 순서를 지키는 편이 낫습니다 — Pro 를 한 달 쓰면서 한도에 걸려 멈춘 날이 며칠인지 세어보세요.

그 숫자가 결정을 대신 해줍니다. 한 달에 한두 번이면 그날만 쉬면 되니 Max 값이 안 나옵니다. 일주일에 두세 번씩 작업 중간에 막힌다면 그때부터는 대기 시간이 곧 비용이라 계산이 달라집니다. Max 안에서도 5배로 시작해서 그래도 모자랄 때 20배로 올라가는 순서가 맞습니다.

③ 한도는 어떻게 세어지나

클로드의 한도는 두 겹입니다. 5시간 세션 창과 주간 한도입니다. 세션 창은 처음 메시지를 보낸 시점부터 5시간이고, 그 안에서 쓸 수 있는 양이 정해져 있습니다. 걸리면 다음 창이 열릴 때까지 기다립니다.

코드 작업에서 이게 체감되는 이유는 대화가 길어지기 때문입니다. 클로드 무료의 벽이 기능이 아니라 사용량이라는 것과 같은 구조인데, 코드베이스를 읽히고 고치게 하면 한 번 주고받을 때마다 들어가는 양이 일반 대화보다 훨씬 큽니다. 그래서 같은 Pro 라도 채팅으로 쓸 때와 코드로 쓸 때 체감 한도가 전혀 다릅니다.

아끼는 방법은 하나뿐입니다. 필요한 파일만 열게 하고, 한 세션에 한 가지 일만 시키는 것. 긴 대화를 계속 이어가는 것보다 새 세션에서 필요한 것만 다시 주는 편이 한도를 훨씬 오래 씁니다.

④ 구독 말고 API 종량제라는 길

클로드 코드는 구독 대신 API 키로 붙여서 쓴 만큼 내는 방식도 있습니다. 월 정액이 아니라 토큰 단위 종량제라 성격이 완전히 다릅니다.

어느 쪽이 싼지는 사용량에 달렸습니다. 가끔 쓰는 사람은 종량제가 싸고, 매일 쓰는 사람은 구독이 거의 항상 쌉니다. 구독은 한도가 있는 대신 예측 가능한 값이고, 종량제는 한도가 없는 대신 청구서가 얼마 나올지 미리 모릅니다. 코드 작업은 토큰을 많이 먹는 쪽이라, 매일 쓰면서 종량제를 고르면 월 $20 을 넘기기 쉽습니다.

토큰 단가는 모델마다 다르고 조정도 잦습니다. 이 사이트에서 원화로 환산해 적어두면 오히려 틀린 정보가 되기 쉬워서, 종량제를 고민 중이라면 공식 요금 페이지 ↗에서 그 시점 단가를 직접 보시길 권합니다. 판단 기준만 말씀드리면 이렇습니다 — 한 달에 며칠이나 쓸 것 같은지가 거의 전부입니다.

그래서 이 글의 표를 요금이 아니라 "들어 있나"부터 시작하도록 만들었습니다. 검색해서 들어온 사람이 첫 화면에서 확인해야 하는 건 가격이 아니라 무료로는 안 된다는 사실이라고 봤기 때문입니다. 그걸 알고 나면 나머지는 Pro 냐 Max 냐 하나로 줄어듭니다.
