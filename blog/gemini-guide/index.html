제미나이 사용법 — 구글 서비스와 붙여 쓰는 법

제미나이를 그냥 챗봇으로만 쓰면 절반만 쓰는 겁니다. 지메일·드라이브·할 일·캘린더에 연결해두면 "그 메일 어디 갔지"를 직접 뒤지지 않고 물어보면 됩니다. 무엇을 연결할 수 있는지, 무엇이 무료고 무엇이 유료가 필요한지 공식 안내 기준으로 정리했습니다.

✓ 연결 가능한 앱 5종 ✓ 켜는 조건 ✓ 무료 vs 유료 구분 ✓ 공식 안내 기준

한 줄 요약

제미나이 앱 설정에서 Gmail·Drive/Docs·Tasks·Keep·Calendar 다섯 가지를 연결할 수 있습니다. 연결 자체는 무료 계정에서도 됩니다. 다만 Docs 안에서 제미나이가 직접 초안을 써주는 맞춤 문서 만들기는 별도 기능이고, 이건 유료가 필요합니다. "연결해서 찾아보기"와 "안에서 만들어주기"를 헷갈리면 안 되는 이유가 여기 있습니다.

연결할 수 있는 다섯 가지

제미나이 앱 설정에서 켜면, 대화창에서 바로 이렇게 물어볼 수 있습니다. 예시는 전부 구글 공식 도움말이 직접 든 것입니다.

연결 앱이렇게 물어볼 수 있습니다
Gmail"지호가 이메일에서 제안한 설악산 여행 날짜가 언제였지?"
Drive / Docs"내 드라이브에서 가장 최근 임대 계약서를 찾아서 보증금 금액 확인해줘"
Google Tasks"캠핑 여행 계획을 세우고 가져갈 물건 목록을 Tasks 에 추가해줘"
Google Keep"쿄토 방문 장소 추천을 Keep 에 저장해줘"
Google CalendarGmail 과 함께 연결하면 이메일 내용을 확인해 일정으로 추가

Drive/Docs 예시가 특히 쓸모 있습니다. "제목에 2023년 6월이 들어간 이력서 찾아서 요약해줘"처럼 파일을 뒤지지 않고 내용부터 물어보는 방식입니다. 파일이 몇백 개씩 쌓인 드라이브를 쓰는 사람이라면 검색창에 파일명을 추측해서 넣는 것보다 훨씬 빠릅니다.

켜기 전에 맞춰야 할 조건 세 가지

연결 버튼을 눌러도 안 될 때가 있습니다. 공식 안내가 요구하는 조건은 이렇습니다.

  • 같은 계정으로 로그인 — 제미나이와 연결하려는 서비스(지메일 등)가 같은 구글 계정이어야 합니다
  • 활동 기록 보관 사용 설정 — 꺼져 있으면 연결 자체가 안 됩니다
  • 지메일의 "다른 Google 제품의 스마트 기능" 켜기 — Gmail 연결에는 이 설정도 따로 필요합니다

회사·학교 계정이면 하나 더 있습니다. Google Workspace 관리자가 앱 연결 기능을 먼저 허용해야 직원·학생 화면에 연결 옵션 자체가 나타납니다. 개인 계정이 아닌데 연결 버튼이 안 보인다면 본인 설정이 아니라 관리자 쪽을 먼저 확인하는 게 맞습니다.

여기서부터는 유료가 필요합니다 — Docs 안의 제미나이

위에서 설명한 "연결"은 바깥에서 안을 들여다보는 방식입니다. 제미나이 대화창이 지메일·드라이브 내용을 가져와 보여주는 것이지, 문서 자체를 만들어주진 않습니다.

Google Docs 안에 직접 들어가 있는 제미나이는 다른 기능입니다. 드라이브·챗·지메일·웹의 정보를 종합해서 제안서나 프로젝트 계획, 블로그 글 같은 맞춤 문서를 처음부터 써주고, 다른 문서의 어조·문장 구조·레이아웃을 그대로 따라 하게 시킬 수도 있습니다. 이건 요구하는 게 다릅니다 — Gemini 가 포함된 Google Workspace, 또는 Google AI Pro·Ultra 계정이 있어야 합니다. 개인 계정이면 Workspace Experiments 라는 별도 테스터 프로그램으로도 접근할 수 있고, 지금은 데스크톱에서만 됩니다.

정리하면 — 찾아보고 요약하는 건 무료로 연결만 하면 되고, 문서를 직접 써달라고 시키는 건 유료입니다. 어느 요금제가 필요한지는 이미 정리해 뒀습니다.

Pro 와 Pro 아래 무료의 차이가 궁금하다면

Docs 문서 생성처럼 유료가 필요한 기능과, 저장용량·동영상 생성처럼 무료에서 막히는 지점을 같이 정리했습니다.

실제로 붙여 쓰는 순서

처음 켤 때는 한꺼번에 다 연결하지 말고 순서대로 해보는 걸 권합니다.

  • Gmail 부터 — 가장 자주 쓰게 되는 연결입니다. "그 사람이 보낸 파일 언제였지" 류의 질문이 제일 흔합니다
  • Drive/Docs 를 그다음 — 파일이 많이 쌓인 계정일수록 체감이 큽니다
  • Tasks·Keep 은 필요할 때 — 이미 다른 할 일 앱을 쓰고 있다면 급하지 않습니다
  • Calendar 는 Gmail 과 묶어서 — 단독보다 이메일 확인과 같이 쓸 때 값어치가 큽니다

연결해두고 안 쓰는 것도 문제없습니다. 각 서비스는 제미나이 앱 설정에서 언제든 개별적으로 끌 수 있습니다.

이 페이지는 구글 공식 도움말(Gemini 앱 고객센터, Docs 편집기 고객센터)의 안내를 기준으로 정리했습니다. 기능은 업데이트로 자주 바뀌는 영역이라, 화면에 나오는 옵션이 다르다면 그게 최신입니다.

이 글을 쓰면서

처음엔 "AI Overviews", "서클 투 서치" 같은 걸 다 묶어서 쓰려고 했는데, 공식 문서에서 확인이 안 되는 항목은 다 뺐습니다. 검색으로 나오는 요약 글에는 있는데 구글 공식 페이지에서 직접 확인되지 않는 내용이 꽤 있었고, 그런 걸 넣기 시작하면 이 사이트가 지키는 "직접 확인" 이 깨진다고 판단했습니다.

대신 확실히 확인되는 것 — Gmail·Drive·Tasks·Keep·Calendar 연결과 예시 문장, 그리고 켜는 조건 — 만 넣었습니다. 특히 Docs 안의 제미나이가 유료라는 걸 명확히 적은 글이 드물다는 게 눈에 띄었는데, 연결 기능과 이름이 비슷해서 헷갈리기 쉬운 지점이라 이 사이트에서는 확실히 갈라 적었습니다.

이어서 볼 만한 것
제미나이 요금제 전체 Plus·Pro·Ultra 차이와 학생 12개월 무료 유료 전환, 언제가 이득인가 Plus 와 Pro 를 가르는 건 저장용량입니다 전체 글 목록 요금표에 안 적혀 있는 것들

자주 묻는 질문

2026년 9월 8일 구글 공식 도움말 확인 기준입니다.

제미나이로 지메일 내용을 검색할 수 있나요?

됩니다. Gemini 앱 설정에서 Gmail 을 연결된 앱으로 켜면 이메일에서 정보를 찾아 요약해 줍니다. 다만 조건이 있습니다 — 제미나이와 지메일이 같은 계정으로 로그인돼 있어야 하고, 활동 기록 보관이 켜져 있어야 하며, 지메일 설정에서 다른 구글 제품의 스마트 기능도 켜야 합니다. 회사·학교 계정이면 관리자가 앱 연결 기능을 먼저 허용해야 보입니다.

제미나이가 캘린더에 일정을 추가해줄 수 있나요?

됩니다. Gmail 과 Calendar 를 함께 연결하면 이메일 내용을 확인해 캘린더에 일정으로 추가하는 식의 요청이 가능합니다. Tasks 를 연결하면 할 일 추가·수정도, Keep 을 연결하면 메모 작성과 저장도 시킬 수 있습니다. 전부 무료 계정에서도 연결 자체는 가능합니다.

Docs 안에서 제미나이로 문서를 만들려면 유료여야 하나요?

네, 이건 유료가 필요합니다. Gmail·Drive 검색과 달리 Docs 안에서 제미나이가 직접 초안을 쓰고 다른 문서의 스타일을 따라 하는 맞춤 문서 만들기 기능은 Gemini 가 포함된 Google Workspace, 또는 Google AI Pro·Ultra 계정이 있어야 쓸 수 있습니다. 개인 계정은 Workspace Experiments 라는 별도 테스터 프로그램으로도 접근할 수 있고, 현재는 데스크톱에서만 됩니다.
