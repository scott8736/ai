미드저니 사용법 — Fast·Relax 모드와 플랜별 차이

미드저니는 무료 플랜이 없다는 것부터 다른 AI 툴과 다릅니다. 디스코드에서 어떻게 쓰는지, Basic·Standard·Pro·Mega 네 플랜이 속도와 공개 범위에서 정확히 어떻게 갈리는지 공식 문서 기준으로 정리했습니다.

✓ 디스코드 기본 흐름 ✓ Fast vs Relax ✓ Stealth 모드 조건 ✓ 2026년 9월 10일 확인

한 줄 요약

미드저니는 무료 플랜이 없습니다. 이미지를 한 장이라도 만들어보려면 최소 플랜을 결제해야 합니다. 플랜은 Basic·Standard·Pro·Mega 네 단계이고, 갈리는 기준은 성능이 아니라 얼마나 빨리 만들 수 있는지(Fast/Relax) 와 결과물을 비공개로 할 수 있는지(Stealth) 입니다.

기본 흐름 — 디스코드에서 시작합니다

미드저니는 별도 앱이 아니라 디스코드 안의 봇으로 작동합니다. 특별한 하드웨어 없이 디스코드 채널에서 미드저니 봇에게 명령어로 프롬프트를 보내면 이미지가 생성됩니다. 명령어로 이미지를 만들고, 기본 설정을 바꾸고, 계정 정보를 확인하는 것까지 전부 디스코드 명령어로 처리합니다.

Fast 모드 vs Relax 모드

생성 속도를 정하는 게 GPU 속도 모드입니다. 공식 문서가 설명하는 핵심은 이렇습니다.

  • Fast 모드 — 빠르게 생성되지만, 플랜마다 정해진 시간만큼만 쓸 수 있습니다
  • Relax 모드 — 느리지만 제한이 느슨합니다. 다만 Basic 플랜 구독자는 Relax 모드 자체를 쓸 수 없습니다.
  • Turbo 모드 — Fast 보다도 더 빠른 상위 옵션입니다

repeat 파라미터(같은 프롬프트를 여러 번 반복 생성)는 Fast·Turbo 모드에서만 작동하고 Relax 모드에서는 안 됩니다. Relax 로 여유 있게 쓰다가 급할 때만 Fast 로 전환하는 식으로 속도와 한도를 조절하는 게 기본 운용 방식입니다.

Stealth 모드 — 비공개로 만들기

미드저니로 만든 이미지는 기본적으로 커뮤니티에 공개됩니다. 결과물을 남에게 보이고 싶지 않다면 Stealth 모드가 필요한데, 공식 문서 기준으로 Pro 플랜과 Mega 플랜에서만 됩니다. Basic·Standard 로는 비공개 생성이 안 됩니다.

업무용으로 만드는 이미지, 아직 공개 전인 프로젝트 시안처럼 남에게 보이면 안 되는 작업이라면 플랜을 고를 때 이 조건부터 확인해야 합니다.

이 글을 쓰면서

미드저니 요금제 페이지는 오늘 두 번의 시도 모두 접근이 막혔습니다. 대신 도움말 문서 여러 개에서 확인한 사실 — 무료 플랜이 없다는 것, 플랜 이름과 개수, Fast/Relax/Stealth 가 정확히 어느 플랜부터 열리는지 — 만 모아 이 글을 만들었습니다.

검색해서 나오는 다른 글들은 대부분 플랜별 정확한 시간(GPU 아워)까지 구체적으로 적어놓는데, 저는 오늘 그 숫자를 공식 문서에서 직접 확인하지 못했습니다. 확인 안 된 숫자를 적느니 확실한 것만 적고 나머지는 링크로 넘기는 쪽을 택했습니다.

미드저니 무료 플랜이 있나요?

없습니다. 공식 안내 기준으로 미드저니는 전 플랜이 유료 구독입니다. 예전에 있던 무료 체험이 사라진 뒤로 이미지를 생성해보려면 최소 요금제를 결제해야 합니다. 다만 정확한 플랜별 금액은 이 글에 적지 않았습니다 — 공식 요금 페이지에서 확인하세요.

Fast 모드와 Relax 모드는 뭐가 다른가요?

생성 속도가 다릅니다. Fast 모드는 빠르게 생성되는 대신 매달 정해진 시간만큼만 쓸 수 있고, Relax 모드는 느린 대신 제한이 느슨합니다. 공식 문서에 따르면 Basic 플랜 구독자는 Relax 모드 자체를 쓸 수 없고, 상위 플랜(Standard·Pro·Mega)부터 Relax 모드가 열립니다.

Stealth 모드는 어느 플랜부터 되나요?

공식 문서 기준으로 이미지와 영상을 비공개로 만드는 Stealth 모드는 Pro 플랜과 Mega 플랜에서만 됩니다. Basic·Standard 플랜에서 만든 이미지는 기본적으로 커뮤니티에 공개됩니다.
